# ステータスバーメーカー

ココフォリアのキャラの HP・MP・SAN などを、OBS に好きなデザインで映すための「カスタム CSS」を作るツール。

**公開サイト: https://shiki365.github.io/status-bar-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

## できること

- **ひな形 9 種** — 標準（黒地＋赤青紫）/ ミニマル / SF・HUD / 古文書（クトゥルフ）/ 和風 / ポップ / ホラー / レトロゲーム / カード（アイコン付き）
- **並び** — ステータスの本数（1〜8）、縦・横・何列か、バーの大きさ、文字の置き方（重ねる / 上 / 下 / 横並び / ラベルだけ外）、キャラのアイコンとイニシアチブ
- **バー** — 形（角丸・カプセル・平行四辺形・面取り・矢印・片側カット）、枠線（二重線も）、下地、塗り（単色・グラデーション・つや・斜線・ネオン）、区切り、増減の速さ、1 本ずつの色と表示名と記号
- **文字・名前** — フォント 40 種（Google Fonts と PC のフォント）、大きさ、ふちどり、名前の位置（上 / バーの上 / 下 / 左・縦書き / アイコンに重ねる）と見た目
- **演出** — 残り○%未満で光る・点滅・震える・色が変わる、0 になったら灰色、ココフォリアの赤い数字（80% 以下）の色
- **飾り** — 背景パネル（古い紙・ざらつき）、光沢、外側の光、先端の光、流れる光、走査線、目盛り、ざらつき、角のかっこ
- **キャラの一覧** — ルーム URL とキャラクター ID から OBS 用の URL を作り、名前と色を書き込んだ CSS をキャラごとにコピー
- プレビューで数値を動かして確認、ブラウザソースの大きさを自動で計算、元に戻す / やり直す、自動保存、プロジェクトファイル

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と CSS |
| `presets.v1.js` | フォント・記号・形・飾り・ひな形の一覧（データだけ） |
| `shapes.v1.js` | バーの形（SVG パス）、記号、枠線やざらつきの SVG |
| `model.v1.js` | 状態（初期値、ひな形の適用、読み込み時の補完）、ココフォリアの URL |
| `css.v1.js` | 状態 → カスタム CSS（UI に依存しない。プレビューと書き出しで同じ関数） |
| `deco.v1.js` | 飾りと、ピンチ・0・赤い数字の演出 |
| `mock.v1.js` | プレビュー用に再現したココフォリアのキャラ画面 |
| `app.v1.js` | UI、履歴、自動保存（localStorage）、コピーと保存 |

## 仕組み

OBS のブラウザソースで `https://ccfolia.com/rooms/{ルームID}/characters/{キャラクターID}` を開くと、ココフォリアがそのキャラのアイコンとステータスだけの画面を出す。ツールが作るのは、その画面の見た目を上書きする CSS。

画面の作りは、ココフォリアの配布している JavaScript から読み取った（2026-09-14）。

```
#root > div > div
  span.MuiBadge-root   … アイコン + span.MuiBadge-badge（イニシアチブ）
  div > div[variant="bar"]
    div                … ステータス 1 本（最大 8 本）
      div > p（ラベル）+ p（<span color>現在値</span>/最大値）
      div > div（下地）+ div（伸び縮みする部分, style="width: 83.3333%;"）
```

- 数字の `span` は、**現在値が最大値の 80% 以下**になると `color="secondary"` になる（0 以下ではない）
- 残りの割合は `style` 属性の先頭一致（`[style^="width: 8"]` など）で判定し、`:has()` で 1 本ぶんの器に演出を掛けている。`:has()` は OBS 30（Chromium 105 以降）から
- 名前はこの画面に無いので、`:root { --name: "…" }` として CSS に書き込み、疑似要素で出す
- プレビュー（`mock.v1.js`）はココフォリア側の元のスタイルも再現していて、CSS が上書きし忘れたものはプレビューでも崩れて見える

## 増やし方

- **ひな形** — `presets.v1.js` の `DESIGNS` に 1 つ足す。`BASE_LOOK` に対する差分だけ書けばよい
- **飾り** — `presets.v1.js` の `DECO_TYPES` に名前と調整項目（`controls`）を、`deco.v1.js` の `DECOS` に CSS を作る関数を足す。UI は `controls` から自動で作られる
- **バーの形** — `presets.v1.js` の `SHAPES` に名前を、`shapes.v1.js` の `PATHS` にパスを作る関数を足す。枠線はパスを太く描いて自分自身で切り抜くので、どんな形でも内側に沿う
- **フォント** — `presets.v1.js` の `FONTS` に足す。`weights` は Google Fonts に実在する太さだけにする（存在しない太さを頼むと読み込み全体が失敗することがある）

## 気をつけること

- ココフォリアの画面の作りが変わると、表示が崩れることがある
- Google Fonts を使うので、OBS の PC がインターネットにつながっている必要がある
- 「ステータスを隠す」にしたキャラは、持ち主以外にはバーが表示されない（ココフォリアの仕様）
