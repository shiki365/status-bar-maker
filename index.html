ステータスバーメーカー

ココフォリアのキャラの HP・MP・SAN などを、OBS に好きなデザインで映すための「カスタムCSS」を作ります。数値はココフォリアと連動して動きます。すべてブラウザの中だけで処理され、入力した内容がどこかに送られることはありません。

ステータスの数

ココフォリアのキャラの「ステータス」に合わせます。上から1本目・2本目…の順に色が付きます（ココフォリアが表示するのは最大8本です）。

「英数」のフォントは、日本語の部分だけ PC のゴシック体になります。そのフォントに無い太さは、いちばん近い太さになります。

「名前で指定」では、この PC に入れたフォントが使えます。OBS を動かす PC にも同じフォントが入っている必要があります。

名前

ココフォリアのこの画面には名前が出ないため、CSS の中に書き込みます。キャラごとの名前は「キャラ・保存」タブで入れられます。

ピンチの演出

どのバーで使うかは「バー」タブの ⚠ で選べます。

0 になったとき
減るほど壊れていく

ひびは残りが 75%・50%・25% を切るたびに増え、0 で砕けます。アイテムは右から順に壊れます。並べる数を最大値と同じにすると、1 点減るごとに 1 つ壊れます（HP 12 なら 12 個）。アイテムを置くと、バーの左の「記号」は出ません。

ココフォリアの赤い数字

ココフォリアは、現在値が最大値の 80% 以下になると数字を赤くします（ピンチの判定とは別です）。使わないときは、減っても普段の文字色のままです。

飾り

ピンチ・0・壊れていく演出は OBS 31 以降で動きます（それより古い OBS では演出だけが出ません）。

ルーム

ココフォリアでルームを開いたときの URL を貼ります。

キャラ

キャラクター ID は、盤面のコマを右クリック →「Copy Id (for dev)」でコピーできます。コマの URL をそのまま貼っても構いません。
OBS に映るキャラは、ブラウザソースの URL で決まります（CSS が変えるのは、見た目と名前・色だけです）。キャラごとに新しいブラウザソースを作り、「① URL をコピー」を URL に、「② CSS をコピー」をカスタム CSS に貼り付けてください。

プロジェクト

作業内容はこのブラウザに自動で保存されます。別の PC へ持っていくときやバックアップには「プロジェクトを保存」を使ってください。

OBS での設定

  1. ソースを追加 →「ブラウザ」。URL にキャラの URL を入れます：
    https://ccfolia.com/rooms/{ルームID}/characters/{キャラクターID}
  2. 幅と高さに、上に出ている ブラウザソースの大きさ を入れます。
  3. 「カスタム CSS」の中身を全部消して、コピーした CSS を貼り付けます。
  4. 真っ白のままなら、ソースを右クリック →「対話」でココフォリアにログインしてルームに入ります（1 回やれば覚えています）。
  5. 2 人目からは、「ソースを追加」→「ブラウザ」で新しく作り、URL と CSS をそのキャラのものにします。ブラウザソースは OBS の仕様で複製できず（「複製を貼り付け」は灰色のまま）、「参照を貼り付け」で増やすと全員が同じキャラになってしまいます。大きさや位置は、右クリック →「変換をコピー」→「変換を貼り付け」でそろえられます。

ココフォリアでの設定

  • キャラの「ステータス」の並び順が、1本目・2本目…の色になります（例: HP → MP → SAN）。
  • チャットで :HP-3 :SAN=45 のように打つと、OBS 側もすぐに変わります。
  • 「ステータスを隠す」にしたキャラは、持ち主以外にはバーが表示されません。

PC に入れたフォントを使うとき

  • フォント欄で「名前で指定（PCのフォント）」を選び、フォント名を入れます。Chrome / Edge では「一覧から選ぶ」で、PC に入っているフォントを見た目で選べます（初回はフォントの使用の許可を聞かれます）。
  • OBS は自分の PC のフォントで表示するので、OBS を動かす PC にも同じフォントを入れてください。入っていないと、ふつうのゴシック体になります。
  • 漢字が入っていないフォントでは、漢字の部分だけふつうのゴシック体になります（一覧の見本の「永」で確かめられます）。
ブラウザだけで動く無料ツールです。作った CSS は自由に使えます。
ココフォリアの画面の作りが変わると、表示が崩れることがあります。いずれのサービスとも関係のない非公式のツールです。
